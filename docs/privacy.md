# 公开脱敏说明

公开导出使用独立目录和字段允许清单。原始 Drive、模型、日志和报告没有被覆盖；原始资料不直接压成 ZIP 公开。

## 保留

- 模型、源码、输入版本与公共上游 revision。
- 分辨率、帧数、时长、种子、计时、显存、功率、CPU、RSS 和 I/O 采样。
- 单次请求技术结果、三条主片内容不通过的理由、生成视频和冻结首帧的校验值。
- 小时费率观察值、额度消耗差值、计时估算及尚未对账的差额。
- 关闭的研究状态和没有执行的正式测试项目。

## 去除或重编码

- Google 登录账号、邮箱、机构身份、个人电脑与 WSL 用户路径。
- Drive 文件夹/文件 ID、私有共享地址、会话 UUID、运行时连接地址、OAuth 状态和凭据。
- 账户原始余额和优惠领取/独立授权记录。
- 原始挂载/授权/控制台日志、私人环境归档、二进制内核缓存和模型权重。
- 原始绝对时间、进程 PID 及子进程列表。会话改为 R01/R02，样本改为 P01–P04/M42–M44，资源采样时间从文件首条记录起相对化。

JSON 和 CSV 是按允许字段重新导出的资料，不是完整原始日志。公开许可与引用中的上游作者名称和公开仓库链接属于必要署名，保留不变。

## 验证

`scripts/validate_publication.py` 检查目录中的邮箱、用户路径、Drive 链接、常见凭据格式及不应出现的原始存档。它还检查数据边界、CU 公式和媒体校验清单。私下额外比对已知账号标识和 Drive ID，具体值不写入本仓库。

发布前另执行 `python scripts/validate_publication.py --media-metadata --strict-manifest`，用 Pillow / PyAV 检查可读媒体元数据。压缩音视频负载不能当作普通文本扫描，否则随机字节可能误报邮箱；新添媒体同样需要元数据与实际内容复核。

这些检查不代表任何扫描器可以绝对保证无泄漏。后续新增文件应重新运行检查，并按相同允许清单人工复核。
